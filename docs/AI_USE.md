# AI assistance and author responsibility

AI assistance was used during software implementation, debugging, refactoring,
test development and preparation of source-release documentation. This describes
development assistance, not a requirement for an online AI service at runtime.
The project also contains a separate optional PyTorch correction model.

For the manuscript, the authors should identify the actual tools and versions
from their development records and describe the specific roles and human
verification performed. Do not invent an AI percentage, model version, validation
claim or statement that AI was used only for grammar correction.

Automated regression checks do not replace author review of algorithms, outputs,
citations or scientific conclusions. Before submission, reconcile the final
disclosure with the actual study history and the current Water instructions:
https://www.mdpi.com/journal/water/instructions

The code is not a claim that AI-generated content is free of third-party rights.
Additional identified upstream code must be attributed and licensed appropriately.
